<Section id="spring" title="Spring">

`SpringAnimator` animates several numbers at once. Each spring is set by a duration in seconds and a bounce from 0 to 1, and is exact at any frame rate. Changing the target keeps the current velocity, so reversing mid-way stays smooth, which CSS transitions can't do.

<Install pkg="@fluidkit/core" />

```ts
import { SpringAnimator } from "@fluidkit/core";

const spring = new SpringAnimator(
  { width: 100, radius: 12 },
  { duration: 0.4, bounce: 0.2 },
  ({ width, radius }) => {
    el.style.width = `${width}px`;
    el.style.borderRadius = `${radius}px`;
  },
  () => console.log("at rest"), // optional
);

spring.to({ width: 240, radius: 24 });
spring.to({ width: 100, radius: 12 }, { duration: 0.6, bounce: 0 }); // optionally with new springs
spring.retarget({ width: 110, radius: 12 }); // change the target of the current movement, no new bounce
spring.jump({ width: 120 }); // set a value instantly, keeping its velocity and target
spring.values(); // current values
spring.velocities(); // current speed per channel, units/s (can be passed as to()'s third argument)
spring.stop();
```

Each channel can have its own spring:

```ts
new SpringAnimator(
  { opacity: 0, scale: 1 },
  {
    opacity: { duration: 0.15, bounce: 0 },
    scale: { duration: 0.45, bounce: 0.3 },
  },
  ({ opacity, scale }) => {
    /* … */
  },
);
```

`SpringParams` is `{ duration, bounce, settle? }`:

- `duration` is how long the motion feels, in seconds. It's not a hard deadline.
- `bounce` goes from `0` (no overshoot) to `1`.
- `settle` is the bounce after the first overshoot (default: same as `bounce`). A bouncy spring with a low `settle` overshoots once, then comes back without wobbling.

`to()` starts a new movement with a new bounce; `retarget()` changes the target of the current movement without one.

`SpringAnimator.timeScale` slows down or speeds up all springs at once: `0.25` is four times slower. All packages use these springs, so one setting slows down Morph, Indicator, Drag and Lift together, like the speed control in the [playground](/playground).

```ts
SpringAnimator.timeScale = 0.25; // slow motion
SpringAnimator.timeScale = 1; // back to real time
```

<Section id="box" title="Boxes">

Morph and Indicator measure elements with these: position, size, and corner radii as the browser draws them. Corners are always circular: percentages resolve against the box, and elliptical corners use the smaller radius. When corners on one side add up to more than the side's length, all of them shrink proportionally, so a capsule's `9999px` becomes half its height.

```ts
import { measureBox, radiiCss, still } from "@fluidkit/core";

// Its box on screen, ignoring inline transforms (like a press effect's)
const box = still(el, () => measureBox(el, true));
// { x, y, width, height, radii: [tl, tr, br, bl], shape }

other.style.borderRadius = radiiCss(box.radii);
```

| Export | Description |
| --- | --- |
| `measureBox(el, cornerShapes)` | The element's box on screen, its corner radii, and the top-left `corner-shape` as a superellipse exponent (`1` round, `2` squircle; always `1` unless `cornerShapes`) |
| `radiiOf(style, width, height)` | The four corner radii from a computed style, fitted to that size |
| `cornerOf(value, width, height)` | One computed corner (`10px`, `10%`, `10px 20px`) as a single circular radius |
| `fitRadii(radii, width, height)` | Shrinks radii the way the browser does when they don't fit |
| `cornerShapeOf(style)` | The top-left `corner-shape` as a superellipse exponent, so it can be animated |
| `drawsCornerShape(window)` | Whether the browser supports `corner-shape` |
| `radiiCss(radii, scale?)` | Radii as a CSS value, collapsed to one value when all are equal |
| `still(el, read, to?)` | Runs `read` with the element's inline transforms removed, then restores them in the same task, so nothing flickers |
| `px(value)` | Rounds a length to a hundredth of a pixel |

<Section id="clicks" title="Clicks and selection">

Gestures can cause unwanted side effects. Releasing a drag over the button where it started fires a click; dragging a pointer across the page selects text. Drag, Indicator and Liquid Blur's stretch use these helpers to prevent that.

| Export | Description |
| --- | --- |
| `swallowClick(document, except?, ms?)` | Cancels the next click in the document within `ms` (default `400`), except on `except`. Returns a function that stops waiting; call it before waiting again and on destroy |
| `holdSelection(document)` | Prevents text selection on the page until released: sets `user-select: none` on the root (and turns off the iOS callout) and clears any current selection. Nested calls are counted. Returns a release function; the root's styles come back after the last release |

</Section>

<Section id="react" title="React" only="react">

`@fluidkit/core/react` has the helpers the packages' React components are built from. You can use them for your own components on top of an engine.

| Export | Description |
| --- | --- |
| `renderPart(tag, props, render, state)` | Renders a part as `render` specifies, as in Base UI: your element with our props merged in, a function of props and state, or `tag` |
| `mergeProps(ours, yours)` | Merges props: joins classes, merges styles (yours win), calls both handlers (yours first; ours skipped if yours called `preventDefault()`), sets both refs |
| `useMergedRefs(...refs)` | Combines refs into one stable ref. A new ref each render would make React detach and reattach the element |
| `useAttach(fn)` | A stable ref that calls `fn(el)` when the element mounts and its cleanup when it unmounts. Works the same in React 18 and 19 |
| `useControllable(value, defaultValue, onChange)` | State that's controlled when `value` is given, uncontrolled otherwise |
| `useSettings(engine, settings, taken)` | After each render, passes only the changed settings to the engine's `set()` |
| `useLatest(value)`, `useBatched(fn)`, `useIsomorphicLayoutEffect` | The latest value for callbacks; runs `fn` once at the end of the current task; a layout effect that doesn't warn on the server |

```tsx
import { SpringAnimator } from "@fluidkit/core";
import { renderPart, useAttach, type RenderProp } from "@fluidkit/core/react";

function Spinner({ render }: { render?: RenderProp<{}> }) {
  const ref = useAttach<HTMLElement>((el) => {
    const spring = new SpringAnimator({ r: 0 }, { duration: 1, bounce: 0 }, ({ r }) => (el.style.rotate = `${r}deg`));
    spring.to({ r: 360 });
    return () => spring.stop();
  });
  return renderPart("span", { ref, className: "spinner" }, render, {});
}
```

<Section id="contract" title="Contract">

The packages never import each other. Instead, each one marks what it does with DOM attributes and reads the attributes set by the others, so each works alone and any combination works together. The attribute names are exported as constants and only change in a major version.

| Attribute | Constant | Set by | Meaning |
| --- | --- | --- | --- |
| `data-fk-surface` | `SURFACE` | Liquid Blur's melt, on a group root | The children share one glass surface. A morph from one of them lifts its glass above the others or merges with them |
| `data-fk-part` | `PART` | Melt and Morph on elements they create; Indicator on its indicator | Not content: Morph ignores it as a neighbor, press effects ignore it |
| `data-fk-away` | `AWAY` | Morph, on hidden states | Temporarily not glass: melt skips it. A state that kept focus is still focusable |

</Section>
